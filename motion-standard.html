接入一个人物

全身共用一套身体单位。静止人物面向 +x，+y 指向人物左手，+z 向上，脚底位于 z = 0。侧别数组一律先右后左。角度用弧度，时长用秒。体型给出真实的身体比例，切片密度控制每个身体单位里有多少个像素。

体型标签参考身高内置人物与动作
adult50徒步者、测绘员和妈妈。可跑跳、用手机、打字和击掌。
child34学龄儿童。跑跳幅度按自己的身高计算，可使用设备或与大人击掌。
toddler28学步幼儿。可走、跑、跳、爬，也能与儿童或大人击掌。
baby22小宝宝。可坐、爬、挥手、拍手，或作为搭档被抱起。

将扩展脚本放在 studio-library.js 之后、studio.js 之前加载。人物和动作各自使用唯一的 ID，首字母为小写英文，其后可含小写字母、数字、下划线和短横线。下面的例子用现有儿童画法换一件紫色外套，注册后即可参加跑步和击掌。

const violetCoat = {
  ...familyArt.child,
  materials: { ...familyArt.child.materials,
    blue: '8568aa', blueLight: 'b79bcb', blueDeep: '654c89' }
};
PineMotion.registerCharacter({
  id: 'violet_child', label: '紫衣小朋友',
  rig: 'child', art: violetCoat, density: 2, tags: ['child']
});

自绘外观提供 materials 和 paint(pose, brush, ink)。色值使用六位 RGB 十六进制字符串。brush.frame(pose.head) 或 brush.frame(pose.torso) 让后续像素跟随头或躯干。绘制四肢前调用 brush.frame(null)，沿已求解的关节使用 brush.link。brush.blob 可画圆形部件，brush.stamp 可逐点采样衣纹。密度 2 表示每个轴每单位采两格。

已有体型可直接填写名称。新增体型时传入参数对象，包含正数 height, ankle, thigh, shin, upperArm, forearm, palm 和三维坐标 pelvis, hip, shoulder, neck, mouth。髋、肩坐标中的 y 填左右对称距离。可用 box: [宽x, 宽y, 高z] 为大幅下蹲、伸手和道具预留采样空间。四种体型的完整参数 · 四个人物的外观画法

编写一个动作

每个动作声明默认时长、角色槽位和采样函数。sample(u, 主角, 搭档) 接收 0 至 1 的进度，返回本帧的演出人物数组。用传入的进度计算姿势，便可随时拖动时间、重复播放或改速。相同的时间与人物应得到相同的结果。

PineMotion.registerAction({
  id: 'look_around', label: '看看四周', group: '日常', seconds: 2.4,
  roles: [['adult', 'child', 'toddler']],
  sample(u, actor) {
    const pose = PineMotion.rig.pose(actor.rig, {
      headYaw: 0.38 * Math.sin(2 * Math.PI * u)
    });
    return [{ character: actor.id, x: 0, y: 0, z: 0, heading: 0, pose }];
  }
});
接口约定
x, y, z, heading人物根节点在片段场景中的位置与绕 z 轴的朝向。跳跃的整体腾空写入根节点 z，脚、头和道具一起升降。
rig.pose(rig, channels)可指定骨盆偏移 hipOffset、躯干和头部的转角、左右脚踝 feet、手掌目标 hands，以及指引膝肘弯曲方向的 kneePoles 和 elbowPoles。手脚目标均为人物局部坐标。
posetorso、head 是按行存储的 3 × 4 刚体矩阵。legs 提供 hip、knee，feet 提供 ankle。arms 提供 shoulder、elbow、wrist、hand。blink 从 0（睁眼）到 1（闭眼）。
pose.props数组中的每项为 {kind, frame, scale}，内置 phone、laptop、stool。frame 把道具局部坐标变换到人物空间，scale 统一调整大小。水瓶沿用 pose.bottle 的 base、lip、held。

让设备和人物对准时，可先用 rig.point(frame, 接触点) 算出目标，再交给手臂求解。手机的玻璃面在道具 x = 0 处，笔记本的键盘面在 z = 0 附近。跑跳、手机和键盘动作 · 设备与坐凳的像素绘制

让两个人碰到同一点

roles 有几个槽位，就按顺序传入几个人。每个槽位列出允许的标签，命中任意一个即可。击掌的两个槽位都接受 adult、child 或 toddler。托抱和躲猫猫使用 [['mother'], ['baby']]。兼容的新照护者可声明 tags: ['adult', 'mother']，并校准手臂和宝宝接触点。

每个人物都有命名接触点 mouth、rightEye、leftEye、seat（臀侧）和 upperBack（上背）。换服装或体型后如果锚点有偏移，可在注册人物时传入 sockets: { upperBack: { frame: 'torso', point: [-1.95, -1.18, 11.65] } }。point 是相对于静止人物原点的坐标，frame 选 head 或 torso。PineMotion.rig.socket(actor, pose, 'upperBack') 会给出当前姿势下的人物局部坐标。

两个人物共享一个 u。击掌先选一个双方都能触到的场景坐标，再把它分别换算为两人的局部手掌目标。抱起时，宝宝臀侧和上背的接触点随躯干升降，妈妈的两只手分别追踪它们。可从每位演出者的 contacts 读取已求解的场景坐标检查间距。渲染器先把两人投到共同的像素切片，再根据相机角度绘制手臂、衣服和脸的遮挡。

新增互动可在正侧面核对接触，再转到背面查看交错的手臂。想让相邻两段衔接平滑，可以为它们绘制相同的收尾和起始姿势。击掌、托抱和躲猫猫的实现

编排、循环与交换文件

在工坊里选择人物和动作，调整「单次秒数」「重复次数」，再点「加入末尾」。点击时间线中的一段即可修改、替换、移动或删除。「单段试看」只播放编辑中的一段，「返回编排」回到原播放位置。勾选「循环播放」会在整套编排结束后回到第一段。编排本随编辑保存在当前浏览器中，导出的 JSON 可以在其他浏览器导入。

{
  "version": 1,
  "loop": true,
  "steps": [
    { "action": "jump", "actors": ["child"], "seconds": 1.7, "repeat": 2 },
    { "action": "highfive", "actors": ["child", "mother"] }
  ]
}

version 和 steps 必填。loop 默认 false，seconds 默认取动作时长，repeat 默认 1。单次时长须为有限正数，次数须为正的安全整数。空 steps 表示空编排。每段可以换演员，交界处直接切到下一段的起始姿势。独立的片段可以使用各自的出场位置。

const plan = PineMotion.compile({
  version: 1, loop: true,
  steps: [{ action: 'jump', actors: ['toddler'], repeat: 2 }]
});
plan.duration;            // 3.4 秒
plan.locate(1.7);         // 第 0 段，第 1 次重复（从 0 开始计数），u = 0
plan.sample(0.85);        // 第一次跳跃的一帧
plan.sample(plan.duration); // 最后一段的终点姿势

compile 接受对象或 JSON 字符串，验证字段、角色人数和标签，给出段落起点 starts、总时长 duration 和采样器。sample 将越界时间限制在首尾。自定义播放器在 loop 为 true 且总时长大于零时，对播放秒数按总时长取余。结构校验使用下方的 JSON Schema，人物和动作 ID 由当前注册表校验。

把人物放进 Three.js 场景

在动作工坊中点「三维预览」，即可把当前编排放到溪边木平台上。点「从栏杆侧看」，在同一个姿势下开关「显示栏杆」，能看清哪一条栏杆挡住了腿。拖动镜头可以绕到人物身后，也可以从高处看。打开溪畔观景台

在自己的项目里先加载动作库。示例页面从 motion.js 到 studio-library.js 的十个脚本依次构成 PineMotion，可继续加载自定义人物和动作。将宿主项目使用的 Three.js 传入适配器，得到可添加到场景、可移动和旋转的 THREE.Group。以下代码假定宿主已有 scene、camera 和 renderer。

import * as THREE from 'three';
import { createPineCast } from './pine-three.mjs';

const cast = createPineCast(THREE, PineMotion);
scene.add(cast.group);
const plan = PineMotion.compile(PineMotion.presets.play);
const start = performance.now();

// 在宿主已有的渲染循环中调用以下三行。
function renderFrame(now) {
  const t = (now - start) / 1000;
  cast.setTime(plan, t % plan.duration);
  renderer.render(scene, camera);
}
renderer.setAnimationLoop(renderFrame);

// 从场景移除人物时调用 cast.dispose()。

cast.setTime(plan, 秒数) 读取编排，同一动作采样帧可以从任意镜头重复渲染。上例循环播放「放学活动」。播放一般编排时，在 plan.score.loop 为 true 且总时长大于零时取余，一次性播放则传入经过的秒数。已有逐帧姿势也可以直接传给 cast.setFrame(entries)。

适配器从每层有颜色的格子提取外露表面，并把同一平面相邻的同色格合并。每位演员使用一个带顶点颜色的 THREE.Mesh，帽子、手指、手机和键盘一起参与深度测试与光照。人物使用场景灯光。在宿主中打开 renderer.shadowMap.enabled，让光源 castShadow、地面 receiveShadow，人物就能向地面投影。原身体坐标 (x, y, z) 映射为 Three.js 的 (x, z, −y)。默认每身体单位为 0.034 米，成人参考身高为 1.70 米。

可传入 { metersPerUnit: 0.034, sampleRate: 20 } 调整比例和每秒姿势采样次数。镜头可按屏幕刷新率更新。人物的姿势和表面由 CPU 生成，实际场景若需要许多同时活动的角色，应按目标设备测试数量。示例自带 Three.js r187，通过本地 HTTP 服务打开即可。人物适配器 · 示例场景代码 · Three.js 的 BufferGeometry
