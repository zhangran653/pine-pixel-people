接入一个人物

全身共用一套身体单位。静止人物面向 +x，+y 指向人物左手，+z 向上，脚底位于 z = 0。侧别数组一律先右后左。角度用弧度，时长用秒。体型给出真实的身体比例，切片密度控制每个身体单位里有多少个像素。

体型标签参考身高内置人物与动作
adult50徒步者、测绘员和妈妈。可跑跳、用手机、打字和击掌。
child34学龄儿童。跑跳幅度按自己的身高计算，可使用设备或与大人击掌。
toddler28学步幼儿。可走、跑、跳、爬，也能与儿童或大人击掌。
baby22小宝宝。可坐、爬、挥手、拍手，或作为搭档被抱起。

将扩展脚本放在 studio-library.js 之后、studio.js 之前加载。人物和动作各自使用唯一的 ID，首字母为小写英文，其后可含小写字母、数字、下划线和短横线。下面的例子用现有儿童画法换一件紫色外套，注册后即可参加跑步和击掌。

const violetCoat = {
  ...familyArt.child,
  materials: { ...familyArt.child.materials,
    blue: '8568aa', blueLight: 'b79bcb', blueDeep: '654c89' }
};
PineMotion.registerCharacter({
  id: 'violet_child', label: '紫衣小朋友',
  rig: 'child', art: violetCoat, density: 2, tags: ['child']
});

自绘外观提供 materials 和 paint(pose, brush, ink)。色值使用六位 RGB 十六进制字符串。brush.frame(pose.head) 或 brush.frame(pose.torso) 让后续像素跟随头或躯干。绘制四肢前调用 brush.frame(null)，沿已求解的关节使用 brush.link。brush.blob 可画圆形部件，brush.stamp 可逐点采样衣纹。密度 2 表示每个轴每单位采两格。

已有体型可直接填写名称。新增体型时传入参数对象，包含正数 height, ankle, thigh, shin, upperArm, forearm, palm 和三维坐标 pelvis, hip, shoulder, neck, mouth。髋、肩坐标中的 y 填左右对称距离。可用 box: [宽x, 宽y, 高z] 为大幅下蹲、伸手和道具预留采样空间。四种体型的完整参数 · 四个人物的外观画法

编写一个动作

每个独立动作声明大于 0 且至多 10 秒的原始时长、演员槽位和采样函数。将 transition 设为 true 可标记落座、上楼、交接或盖印等会保留结果的片段。sample(u, 主角, 搭档) 接收 0 至 1 的进度，返回本帧的演出人物数组。用传入的进度计算姿势，便可随时拖动时间、重复播放或改速。相同的时间与人物应得到相同的结果。

PineMotion.registerAction({
  id: 'look_around', label: '看看四周', group: '日常', seconds: 2.4,
  roles: [['adult', 'child', 'toddler']],
  sample(u, actor) {
    const pose = PineMotion.rig.pose(actor.rig, {
      headYaw: 0.38 * Math.sin(2 * Math.PI * u)
    });
    return [{ character: actor.id, x: 0, y: 0, z: 0, heading: 0, pose }];
  }
});
接口约定
x, y, z, heading人物根节点在片段场景中的位置与绕 z 轴的朝向。跳跃的整体腾空写入根节点 z，脚、头和道具一起升降。
rig.pose(rig, channels)可指定骨盆偏移 hipOffset、躯干和头部的转角、左右脚踝 feet、手掌目标 hands，以及指引膝肘弯曲方向的 kneePoles 和 elbowPoles。手脚目标均为人物局部坐标。
channels.standing站姿权重范围为 0 到 1。1 让膝盖自然微屈，0 交给当前动作控制。双脚使用默认站位时权重为 1，自定义 feet 时默认为 0。起身时可从 0 平滑过渡到 1。
posetorso、head 是按行存储的 3 × 4 刚体矩阵。legs 提供 hip、knee，feet 提供 ankle。arms 提供 shoulder、elbow、wrist、hand。blink 从 0（睁眼）到 1（闭眼）。
pose.props数组中的每项含 kind、frame 和 scale。内置道具包括 phone、laptop、stool、book、pen、camera、parcel、guitar 等。frame 把道具局部坐标变换到人物空间，scale 统一调整大小。水瓶沿用 pose.bottle 的 base、lip、held。

让设备和人物对准时，可先用 rig.point(frame, 接触点) 算出目标，再交给手臂求解。手机的玻璃面在道具 x = 0 处，笔记本的键盘面在 z = 0 附近。跑跳、手机和键盘动作 · 设备与坐凳的像素绘制

用关键帧编写可复用的手势

PineMotion.keyframedGesture(keys) 生成一个可注册的单人采样器。每帧的 at 从 0 到 1 严格递增，首尾必填。姿势按平滑曲线插值，可直接跳到任意一帧。下面给成人与儿童增加一个抚胸致意的动作。

const greet = { right: [0.34, -0.36, -0.08], head: [0, 0.13, 0] };
PineMotion.registerAction({
  id: 'hand-on-heart', label: '抚胸致意', group: '手势与情绪',
  seconds: 2.8, roles: [['adult', 'child']], keywords: '问候 礼仪',
  sample: PineMotion.keyframedGesture([
    { at: 0 }, { at: 0.32, ...greet }, { at: 0.65, ...greet }, { at: 1 }
  ])
});

right / left 从各自肩关节起算，三个数依次指向前、向身体外侧、向上，单位为这只手臂的可达长度。head / body 依次为偏航、俯仰、侧倾的弧度。shift 以身高为单位移动骨盆，blink 从 0（睁眼）到 1（闭眼）。jawOpen 从 0（闭口）到 1（最大张口）。使用 roles: [['mandible']] 可筛选具有可动下颌的人物。每一帧省略的通道取自然姿势。手势定义与实例

1.19.8 的立体动画人物会读取 pose.faceCue。其中 gaze: [横向, 高低] 的两个数都在 −1 至 1 之间，正值朝人物自身的左方、上方。smile 为加在平时神情上的笑意，范围 0 至 1。关键帧手势可直接写 gaze: [0.6, 0.1]。道具动作可用 PineMotion.rig.lookAt(actor, pose, target) 从双眼中点计算视线，目标点使用人物局部坐标。双人动作先用 rig.local(root, worldPoint) 把目标换到观察者坐标，再调用 lookAt。查看追看摇铃的实现 · 观看双人动作

带物品的动作可在 pose.props 中放入带 kind / frame / scale 的物品。先在道具坐标系声明握点、笔尖或壶嘴，再把它们换算到人物坐标。写字时，一手托住本子，另一手的笔尖沿纸页移动。浇花时，水流从壶嘴落到花土。人和道具的接触 · 物品画法

让两个人碰到同一点

roles 有几个槽位，就按顺序传入几个人。每个槽位列出允许的标签，命中任意一个即可。击掌的两个槽位都接受 adult、child 或 toddler。托抱和躲猫猫使用 [['adult'], ['baby']]，任一成人形象都能扮演照护者。旧编排中的 mother 仍会选中原来的那位演员。

每个人物都有命名接触点 mouth、rightEye、leftEye、seat（臀侧）和 upperBack（上背）。换服装或体型后如果锚点有偏移，可在注册人物时传入 sockets: { upperBack: { frame: 'torso', point: [-1.95, -1.18, 11.65] } }。point 是相对于静止人物原点的坐标，frame 可选 head 或 torso，带下颌骨架的人物还支持 jaw。PineMotion.rig.socket(actor, pose, 'upperBack') 会给出当前姿势下的人物局部坐标。

两个人物共享一个 u。击掌先选一个双方都能触到的场景坐标，再把它分别换算为两人的局部手掌目标。递接包裹时由一人绘制包裹，易手前后使用相同的场景坐标。牵手迈步时双方同步换脚。抱起时，宝宝臀侧和上背的接触点随躯干升降，妈妈的两只手分别追踪它们。可从每位演出者的 contacts 读取已求解的场景坐标检查间距。渲染器先把两人投到共同的像素切片，再根据相机角度绘制手臂、衣服和脸的遮挡。

可用 PineMotion.castFor(clip, actor, preferredPartner) 按角色顺序获得匹配的一对演员。PineMotion.findActions(actor, { domain, group, query, duration, people, ending, eitherRole: true }) 可以按两个角色位置查找动作。传入 null 作为人物可浏览全库。时长值为 brief、short、medium、long，分界为 2、3、5 秒。人数可选 solo 或 pair，收尾可选 return 或 transition。新增互动可在正侧面核对接触，再转到背面查看交错的手臂。想让相邻两段衔接平滑，可以为它们绘制相同的收尾和起始姿势。击掌、托抱和躲猫猫的实现

从库里准备演员和道具

prepareAction 可以只接收动作 ID，也可以指定人物、搭档和场景。结果包含按表演顺序排列的 cast、可直接编排的 step、带数量和库 ID 的 items 及穿搭 wear。从婴儿发起亲子动作时，成人会自动进入照护者槽位。用工坊复演

const ready = PineMotion.prepareAction('family-hear-bell', { actor: 'baby' });
const plan = PineMotion.compile({ version: 1, steps: [ready.step] });
const people = plan.sample(1.2);
const scenery = plan.scenery(1.2);

编写动作时用 items: ['stamp', 'clipboard'] 声明由采样器跟手绘制的物品，数量按同时使用的最大件数填写。双方递同一本书只声明一次，两人各持一把扇子就填两次。seatSlots: [0] 声明成人或儿童使用折叠凳，坐在地面的宝宝会省去该凳。上述 ID 来自 PineWorld.items。

fixtures: [{kind:'puddle', x:7.75, y:0}] 让工坊、场景和 Three.js 自动放入静止布景。横向距离随人物身高缩放，z 使用场景高度单位，heading 使用弧度。传入 scene 和可选的 actorPlacement 时，prepareAction 会在同一层级匹配最近的同类主设施，绑定结果记入 step.target。可自行更换目标下标。场景实例规范

wear: [{slot:'glasses', fallback:'round'}] 按角色槽位声明穿搭。沿用已有眼镜，空槽从人物库借用圆框眼镜。可选 accept 数组限定相容的款式。自定义渲染入口可用 PineMotion.performer(actor, entry.pose) 取得这一帧的穿搭，用该人物的 body 绘制。角色原配方随编排导出，借用品在重放时解析。依赖与接触位置 · 共享物件

编排、循环与交换文件

动作库收录 500 个片段，分为 8 个领域、45 类，可单独播放、导出或组成时间线。工坊提供 18 套循环编排。编排可用 seconds 改速，用 repeat 重复，也可分别编排「上楼」「平台转身」「下楼」。历史文件按保存的时长播放。九段游戏实拍 · 播放楼梯场景 · 下载周末来访

在工坊里选择人物和动作，调整「单次秒数」「重复次数」，再点「加入末尾」。点击时间线中的一段即可修改、替换、移动或删除。「单段试看」播放编辑中的一段，可以勾选循环反复观察。「三维预览」也会带入该段。点「返回编排」回到原播放位置和整套编排的循环设置。勾选「循环播放」会在整套编排结束后回到第一段。编排本随编辑保存在当前浏览器中，导出的 JSON 可以在其他浏览器导入。

{
  "version": 1,
  "loop": true,
  "steps": [
    { "action": "jump", "actors": ["child"], "seconds": 1.7, "repeat": 2 },
    { "action": "highfive", "actors": ["child", "mother"] }
  ]
}

version 和 steps 必填。loop 默认 false，seconds 默认取动作时长，repeat 默认 1。单次时长须为有限正数，次数须为正的安全整数。空 steps 表示空编排。每段可以换演员，交界处直接切到下一段的起始姿势。独立的片段可以使用各自的出场位置。

const plan = PineMotion.compile({
  version: 1, loop: true,
  steps: [{ action: 'jump', actors: ['toddler'], repeat: 2 }]
});
plan.duration;            // 3.4 秒
plan.locate(1.7);         // 第 0 段，第 1 次重复（从 0 开始计数），u = 0
plan.sample(0.85);        // 第一次跳跃的一帧
plan.sample(plan.duration); // 最后一段的终点姿势

compile 接受对象或 JSON 字符串，验证字段、角色人数和标签，给出段落起点 starts、总时长 duration 和采样器。sample 将越界时间限制在首尾。自定义播放器在 loop 为 true 且总时长大于零时，对播放秒数按总时长取余。结构校验使用下方的 JSON Schema，人物和动作 ID 由当前注册表校验。

把人物放进 Three.js 场景

在动作工坊中点「三维预览」，可以把正在试演的单段或整份编排放到溪边木平台上。点「从栏杆侧看」，在同一个姿势下开关「显示栏杆」，能看清哪一条栏杆挡住了腿。拖动镜头可以绕到人物身后，也可以从高处看。打开溪畔观景台

在自己的项目里先加载动作库。示例页面从 motion.js 到 studio-library.js 的脚本按示例页面的加载顺序构成 PineMotion，可继续加载自定义人物和动作。将宿主项目使用的 Three.js 传入适配器，得到可添加到场景、可移动和旋转的 THREE.Group。以下代码假定宿主已有 scene、camera 和 renderer。

import * as THREE from 'three';
import { createPineCast } from './pine-three.mjs';

const cast = createPineCast(THREE, PineMotion, { detail: 'figure' });
scene.add(cast.group);
const plan = PineMotion.compile(PineMotion.presets.play);
const start = performance.now();

// 在宿主已有的渲染循环中调用以下三行。
function renderFrame(now) {
  const t = (now - start) / 1000;
  cast.setTime(plan, t % plan.duration);
  renderer.render(scene, camera);
}
renderer.setAnimationLoop(renderFrame);

// 从场景移除人物时调用 cast.dispose()。

cast.setTime(plan, 秒数) 读取编排，同一动作采样帧可以从任意镜头重复渲染。上例循环播放「放学活动」。播放一般编排时，在 plan.score.loop 为 true 且总时长大于零时取余，一次性播放则传入经过的秒数。已有逐帧姿势也可以直接传给 cast.setFrame(entries)。

适配器从每层有颜色的格子提取外露表面，并把同一平面相邻的同色格合并。标准精度下每位演员使用一个带顶点颜色的 THREE.Mesh，帽子、手指、手机和键盘一起参与深度测试与光照。人物使用场景灯光。在宿主中打开 renderer.shadowMap.enabled，让光源 castShadow、地面 receiveShadow，人物就能向地面投影。原身体坐标 (x, y, z) 映射为 Three.js 的 (x, z, −y)。默认每身体单位为 0.034 米，成人参考身高为 1.70 米。

观景台从第一帧使用 detail: 'figure'，头脸与衣物分别加密，缩远镜头或转动时都能继续使用这套切片。宿主可调用 cast.setDetail('figure')、cast.setDetail('face') 或 cast.setDetail('standard') 切换全身精细、头脸精细和标准精度。省略配置时默认使用标准精度，已有的 faceDetail: true 和 setFaceDetail(true) 仍可开启头脸精细。

可传入 { metersPerUnit: 0.034, sampleRate: 20 } 调整比例和每秒姿势采样次数。镜头可按屏幕刷新率更新。人物的姿势和表面由 CPU 生成，实际场景若需要许多同时活动的角色，应按目标设备测试数量。示例自带 Three.js r187，通过本地 HTTP 服务打开即可。人物适配器 · 示例场景代码 · Three.js 的 BufferGeometry
